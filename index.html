Publicar en GitHub Pages (cero costo)
Pasos para publicar
  1. Creá una cuenta en github.com (gratis)
  2. Creá un repositorio nuevo → nombre: hvdc-calendario
  3. Subí este archivo como index.html
  4. Ir a Settings → Pages → Source: main branch
  5. GitHub te da la URL: tuusuario.github.io/hvdc-calendario
  6. ¡Listo! Compartís esa URL con el grupo
